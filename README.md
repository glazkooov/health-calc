# Калькулятор здоровья (вариант 36)

Лабораторная работа по дисциплине «Проектирование веб-сервисов».
Выполнил: Глазков Г.К., группа 223-321.

## Описание

Приложение считает индекс массы тела (ИМТ) и суточную норму калорий по росту, весу, возрасту, полу
и уровню активности. Каждый расчет сохраняется в базу данных — получается дневник антропометрических данных.

Суточная норма считается по формуле Миффлина - Сан Жеора с коэффициентом активности (от 1.2 до 1.9).

## Состав

| Сервис | Технологии | Порт | Назначение |
|---|---|---|---|
| frontend | HTML, CSS, JS, nginx | 8080 | Веб-интерфейс |
| backend | Python, Flask | 5000 | REST API, работа с БД |
| db | PostgreSQL 16 | - | Дневник измерений |
| calc-service | Python, Flask | 5001 | Расчет ИМТ и калорий |

## Запуск

```
git clone https://github.com/glazkooov/health-calc.git
cd health-calc
docker compose up -d --build
```

После запуска открыть http://localhost:8080

Остановка:

```
docker compose down
```

## API

Backend:
- `GET /api/records` — дневник измерений из БД
- `POST /api/calc` — расчет и сохранение, тело: `{"name": "...", "gender": "m", "age": 20, "height": 175, "weight": 70, "activity": "2"}`
- `DELETE /api/records/<id>` — удаление записи

Сервис расчета:
- `GET /calc?weight=70&height=175&age=20&gender=m&activity=2`

## Интерфейс

- кнопка «Рассчитать» — отправляет данные через backend в сервис расчета и сохраняет результат в БД
- кнопка «Показать дневник» — выводит таблицу всех измерений из БД
